# Trip Desk: 출장 준비부터 보고서까지

노트북에서 출장을 준비해 폰 앱(Trip Field)으로 보내고, 폰에서 내보낸 하루치 데이터를 받아 전사·교정·보고서로 만드는 로컬 도구입니다.
Windows / macOS / Ubuntu 에서 Python 3.10+ 만 있으면 됩니다. 서버는 내 컴퓨터(127.0.0.1)에서만 열리고, **AI 서비스를 직접 부르지 않아요(API 키 불필요)**. AI가 필요한 단계는 프롬프트를 만들어 주고, AI 챗봇의 답을 붙여 넣는 방식이에요.

## 실행
```
pip install -r requirements.txt            # Excel(.xlsx) 가져오기, Word 보고서용
pip install -r requirements-whisper.txt    # (선택) 녹음 → 글 변환. 용량이 커요
python3 -m tripdesk                         # 또는 scripts/install-desk.* 로 설치
```
`--app` 을 붙이면(설치된 아이콘은 이 방식) 주소창 없는 앱 창(Chrome/Edge/Chromium)으로 뜨고, **창을 닫으면 프로그램도 꺼져요**. 터미널은 보이지 않고 오류는 `~/TripDesk/tripdesk.log` 에 남아요. 크롬 계열이 없으면 기본 브라우저로 열리고, 화면의 '프로그램 종료' 버튼으로 끌 수 있어요(창만 닫으면 약 2.5분 뒤 자동 종료). 이미 떠 있을 때 아이콘을 또 누르면 창만 하나 더 열려요.

브라우저가 열립니다. 데이터는 `~/TripDesk/trips/` 에 저장됩니다(`TRIPDESK_HOME` 으로 변경).

## 화면 (왼쪽 메뉴)
| 메뉴 | 하는 일 |
|---|---|
| 출장 목록 | 출장 만들기·삭제, 진행 현황 |
| 사전조사 | 출장 정보, **키워드 → AI 프롬프트**, 후보 업체 표(체크·방문일), 일정 배분 보드, 전시장 맵(대표 1장), 용어집, **패키지 확정** |
| 일간 import | 폰이 내보낸 하루치 ZIP 가져오기, 전사(Whisper) 실행 |
| 일간 보고서 | 업체별 녹음 재생·전사 원문·AI 교정본(수정 표시), 보고서 미리보기, Word/Markdown 저장 |
| 최종 보고서 | 전체 취합, AI 총평 프롬프트, Word/Markdown 저장 |

## 사전조사 흐름
1. 새 출장: 이름·장소·날짜·목적. 알려진 전시회(SPS 2026)는 공식 사이트가 자동으로 채워져요.
2. 지도: 공식 사이트에서 지도 후보를 찾아 받거나, 주소/파일로 직접 추가. 여러 장 중 **대표 1장**만 폰에 가요.
   - **홀 위치 지정**: 같은 탭 아래에서 대표 지도 위에 홀마다 한 번씩 클릭해 위치를 정해요. 폰 지도에는 그날 방문할 업체가 홀별 표시(남은 업체 수)로 떠요. '지도 글자에서 자동 찾기'는 PDF 안에 홀 번호가 글자로 들어 있을 때만 되고(그림 형태면 못 찾음), 찾은 위치는 꼭 눈으로 확인하세요.
3. **참가업체 찾기**: '프롬프트 만들기'에 키워드(예: `휴머노이드, 용접 로봇`)를 적으면 AI 챗봇용 프롬프트가 만들어져요. 이미 목록에 있는 업체는 제외돼요. AI 의 답(JSON)을 붙여 넣으면 후보가 **미선택** 상태로 쌓여요(같은 업체는 합침). 키워드를 바꿔 여러 번 해도 돼요.
   - 근거 URL 이 있는 것만 '참가 확인', 나머지는 'AI 추정' 으로 표시돼요. 패키지 확정 전에 경고해요.
4. 후보에서 방문할 업체를 체크하고 방문일을 정해요(표의 드롭다운, 또는 '일정 배분'에서 홀 기준 자동 배분 후 ◀ ▶ 로 조정). CSV/Excel 가져오기, 직접 추가도 가능해요(열: 업체명, 카테고리, 홀, 부스, 일차 또는 날짜, 메모, 질문).
5. **패키지 확정**: 체크한 업체만 ZIP 에 들어가요. 폰에서 Trip Field → 설정 → '새 출장 · 패키지 불러오기'.

## 하루치 데이터 → 보고서
1. 폰에서 내보낸 ZIP(`days/dayN/visits.json, audio/, photos/`)을 '일간 import'에 올려요. 다른 출장의 ZIP 이면 거절해요. 같은 날을 다시 내보내 올려도 이미 한 전사는 유지돼요.
2. **전사**: faster-whisper 로 이 컴퓨터에서 실행해요(녹음이 밖으로 나가지 않아요). 모델·언어를 고르고, 용어집이 인식 힌트로 쓰여요. 엔진이 없으면 안내 문구가 뜨고, 전사본을 직접 입력할 수 있어요.
3. **교정·요약**: '일간 보고서'의 'AI 교정·요약'이 전사본 + 용어집 + 사전조사 메모로 프롬프트를 만들어요. AI 의 답을 붙여 넣으면 교정본(고친 부분 파랑, `[확인필요: …]` 주황), 업체별 핵심 내용, 하루 요약이 반영돼요. 모두 직접 고칠 수 있어요.
4. **일간 보고서**: 요약 → 업체별 핵심(없으면 전사/교정 원문 그대로) → **내 메모는 원문 그대로** → 사진 → 내일 계획(일정표 기준 자동, 수정 가능) → 확인 필요 목록. Word(사진 포함)·Markdown 으로 저장.
5. **최종 보고서**: 일자별 요약, 업체별 정리, 방문하지 못한 계획 업체, 확인 필요 모음 + AI 총평(프롬프트 방식). Word·Markdown.

시각은 폰이 기록한 시간대(`tzOffsetMin`)로 보여요. 이 값이 없는 예전 파일은 UTC 로 표시해요.

## 전용 창 (크롬 없이, 항상 최대화)
크롬 앱 창은 크롬 쪽 알림(예: "Can't update Chrome")이 뜰 수 있어요. 이를 피하려면 전용 창으로 설치하세요:
`QT=1 ./scripts/install-desk.sh` (Windows: `install-desk.bat qt`). PyQt6 WebEngine(약 500MB)이 들어가고, Ubuntu 는 `sudo apt install libxcb-cursor0` 가 추가로 필요해요. 전용 창은 항상 최대화로 열리고, 링크는 기본 브라우저로 열리며, 파일 저장은 저장 위치를 물어봐요. 설치돼 있지 않거나 시작에 실패하면 자동으로 크롬 앱 창으로 떠요. 강제로 크롬 방식을 쓰려면 환경변수 `TRIPDESK_WINDOW=chrome`.
(이 창은 Linux 가상 화면에서 뜨고 닫히는 것까지만 확인했어요. Windows·macOS 와 파일 저장·복사 버튼은 실제 사용에서 확인이 필요해요.)

## 항공·숙소 (사전조사 → '항공·숙소' 탭)
- **검색 바로가기**: 출발지·목적지·날짜·호텔 등급(성급, 리뷰 평점 아님) 범위를 채운 Google 항공편·Skyscanner(공항 3글자 코드일 때)·Agoda·Hotels.com·Booking·Google 호텔 검색 페이지를 열어요. 호텔은 행사장(장소) 근처로 찾아요. 사이트가 주소 형식을 바꾸면 일부 값(특히 등급 필터)이 안 채워질 수 있어요 — 실제 사이트 동작은 아직 확인하지 못했어요.
- **AI 후보**: 항공편/호텔 후보를 AI 챗봇 프롬프트+붙여넣기로 받아요. 가격·잔여 객실은 AI가 확정할 수 없으니 사이트에서 확인하세요. 후보에서 '예약 기록으로'를 누르면 입력칸이 미리 채워져요.
- **예약 기록**: 항공(편명·시각·예약번호·금액·수하물), 숙소(주소·체크인/아웃·예약번호·금액·무료취소 기한)를 저장하고, 예약 확인 메일을 붙여 넣어 AI 챗봇 으로 정리할 수도 있어요. 통화별 합계와 점검(가는/오는 편 누락, 체크인·아웃이 출장일과 어긋남, 숙소 공백)을 보여 줘요.
- 폰에는 패키지로 전달돼 지도 화면 상단의 ✈ 버튼에서 보이고(숙소 주소는 지도 앱으로 열기), 최종 보고서에는 '이동·숙소·비용' 항목이 들어가요.

## 지도 다운로드 원칙
- 받은 파일의 앞부분(%PDF, JPEG, PNG)을 확인해 진짜 지도 파일일 때만 저장합니다.
- 사이트가 자동 다운로드를 거절하면(403 등) 우회하지 않고 수동 업로드로 안내합니다.

## 알려진 한계 (정직하게)
- **실제 환경 검증 전**: 지도 자동 찾기는 가짜 사이트와 SPS 2026 알려진 주소(실제 응답 미확인)로, 음성 인식은 가짜 엔진으로(실제 모델 다운로드·한국어 정확도 미확인), AI 교정·요약은 형식 파싱만 시험했어요. 실제 AI 챗봇 답변 형식이 어긋나면 붙여 넣기에서 이유를 알려 줘요.
- 참가업체 검색·공식 목록 자동 수집 기능은 없어요(키워드 프롬프트로 대체).
- AI가 준 업체·수치는 틀릴 수 있어요. 출처 링크와 '확인 필요' 표시를 꼭 확인하세요.
- Word 에는 JPG/PNG 사진만 들어가요(HEIC/WebP 는 빠져요).
- 큰 ZIP 은 임시 파일로 받지만, 수 GB 급은 시험하지 않았어요.
- 앱 창 + 자동 종료는 Ubuntu 에서 실제 Chrome(가상 화면)으로 확인했어요. Windows 바로가기(pythonw)와 macOS 앱 묶음은 직접 실행해 보지 못했어요.
- 설치는 `scripts/install-desk.*`(Python 3.10+ 필요). 단독 실행 파일은 아직 없어요.
