# PPT 요청 프롬프트

Trip Desk 최종 보고서 → **PPT용 자료 내려받기**로 받은 ZIP(`최종보고서_PPT용.md` + `photos/`)을 AI 에게 첨부하고, 아래 프롬프트를 함께 주세요.
(박람회 배치도 이미지가 있으면 같이 첨부하면 1장에 들어가요.)

```
첨부한 ZIP 의 최종보고서_PPT용.md 와 photos/ 로 사내 출장 결과보고서를 PowerPoint(16:9)로 만들어 줘.
md 의 순서와 내용을 그대로 따르고, 없는 내용은 만들어 내지 마. md 에 '추가 확인 필요'로 적힌 곳은 그대로 표시해 줘.

[슬라이드 구성]
1장: 목적 / 일정 및 참석자(표) / 박람회 개요(+ 배치도 이미지가 있으면 오른쪽에)
2장: 주요 확인 사항 — 확인 목적 1~2줄 + 표(구분 / 업체 / 수준 / 확인 사항), 표 아래에 수준 범례
3장: 시사점(4칸) / 결론(3칸)
별첨: 업체별 1장씩 — 왼쪽에 사진(원본 비율 유지, 자르지 않음)과 현장에서 확인한 사항,
      오른쪽에 '시사점 및 활용처'. 사진 아래에 출처(현장 촬영)를 작게 적는다.

[작성 원칙]
- 수치, 가격, 고객사, 성능을 새로 추정하지 않는다. md 에 없으면 '추가 확인 필요'.
- 문장은 짧은 개조식. 한 슬라이드에 항목 6개 이내. 감상적인 표현 금지.
- 업체 홍보 문구가 아니라 조선소 적용 관점으로 쓴 md 문장을 그대로 사용한다.

[디자인]
- 흰 배경, 주황색(제목·표 머리글) 포인트, 맑은 고딕
- 슬라이드 상단에 전시회명을 작은 주황색 글씨, 하단에 'Copyright ⓒ 2026 Hanwha Ocean' 과 쪽번호, 사내 보안 문구
- 표 글자 11pt 이상, 본문 14pt 이상 (밀리면 글자를 줄이지 말고 내용을 줄인다)
```
